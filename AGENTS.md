# Repository conventions
Use pnpm. Validate with pnpm test, pnpm typecheck, pnpm build and pnpm test:e2e (running web server required).
Keep business transitions in packages; never trust client balances, deadlines or ownership. Currency is integer lakh. Pure cricket engine must remain independent of React and I/O. Preserve demo labels and distinguish observed data from estimates. Use original artwork, keyboard-accessible controls and reduced-motion support. Never commit credentials. Memory auction store is isolated demo only; production requires transactional PostgreSQL and authentication.
